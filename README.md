# Portal de juegos

Catálogo con filtros (jugadores, duración, tipo, modo) en `games.dsbelda.dev`. Enlaza a Catán y SwJacK y alojará los juegos propios (Brisca, El juego de la Unidad, Parchís…).

- `lib/catalogo.js`: lista de juegos (`estado: 'listo' | 'pronto'`).
- `server.js`: Express, puerto 3400 en `127.0.0.1`.
- `npm test`.
